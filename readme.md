## Features

This OSINT multi-tool allows you to:

* Search for a username across multiple social networks
* Gather information about a given IP address
* Retrieve the IP address behind a URL
* Check if a URL is online or offline

## Installation

Follow these steps to install and run the tool. Each command can be copied and executed separately.

### Clone the repository

```bash
git clone https://github.com/piadi-sudo/IN-COMING.git
```

### Enter the project directory

```bash
cd IN-COMING
```

### Create a virtual environment

```bash
python3 -m venv venv
```

### Activate the virtual environment

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the tool

```bash
python3 main.py
```
