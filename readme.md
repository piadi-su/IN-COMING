## Features

This OSINT multi-tool allows you to:

* Search for a username across multiple social networks
* Gather information about a given IP address
* Retrieve the IP address behind a URL
* Check if a URL is online or offline

![IN-COMING](img/incoming.png)

## Installation
```bash
git clone https://github.com/piadi-sudo/IN-COMING.git

cd IN-COMING

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt

python3 main.py
```
